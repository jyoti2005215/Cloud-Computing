## 1. Aim

To become familiar with Software as a Service (SaaS) and perform basic collaborative activities using cloud-based productivity and communication applications.

## 2. Introduction to SaaS

Software as a Service (SaaS) is a cloud computing service model in which software applications are provided to users over the internet. Users can access SaaS applications through a web browser or application without installing and maintaining the complete software infrastructure on their local computers.

Examples of SaaS applications include:

- Google Docs
- Google Sheets
- Microsoft 365
- Microsoft Teams
- Zoom
- Dropbox
- Salesforce

Common SaaS features include online access, cloud storage, automatic updates, user authentication, file sharing, real-time collaboration, version history, and access from multiple devices.
