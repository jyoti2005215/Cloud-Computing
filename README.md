# Cloud Computing Laboratory – Practical Assignments

## Overview

This repository contains practical assignments covering fundamental concepts and hands-on implementation of Cloud Computing, Virtualization, Computer Networks, Cloud Services, and Distributed Computing.

## Experiments List

| Experiment | Title | Technologies |
|---|---|---|
| 1 | Hypervisor and Virtual Machine | VirtualBox, Hypervisor |
| 2 | Linux VM-to-VM Networking | Ubuntu, Linux Networking |
| 3 | Mininet Network Topology | Mininet, Open vSwitch |
| 4 | Software Defined Networking | SDN, OpenFlow |
| 5 | Cloud Scheduling Lab – MapReduce | Hadoop, Java, YARN |
| 6 | AWS Cloud Services | Amazon Web Services |
| 7 | SaaS – Collaborative Applications | Google Docs, Sheets, Slides |
| 8 | Google App Engine – Platform as a Service | Google App Engine, Python |
| 9 | Hadoop MapReduce | Hadoop, Java, HDFS, YARN |

## Experiments Description

### Experiment 1: Hypervisor and Virtual Machine
Understand virtualization concepts and create virtual machines using a hypervisor.

### Experiment 2: Linux VM-to-VM Networking
Configure and test network communication between two Linux virtual machines.

### Experiment 3: Mininet Network Topology
Create and test virtual network topologies using Mininet and Open vSwitch.

### Experiment 4: Software Defined Networking (SDN)
Explore SDN architecture, network controllers, and OpenFlow concepts.

### Experiment 5: Cloud Scheduling Lab – MapReduce
Understand distributed processing and cloud scheduling using Hadoop MapReduce.

### Experiment 6: AWS Cloud Services
Explore AWS cloud infrastructure, Identity and Access Management (IAM), and CloudWatch monitoring.

### Experiment 7: SaaS – Collaborative Applications
Explore Software as a Service through cloud-based collaborative applications such as Google Docs, Google Sheets, and Google Slides.

### Experiment 8: Google App Engine – PaaS
Develop and deploy a web application using Platform as a Service (PaaS).

### Experiment 9: Hadoop MapReduce
Implement a Word Count application using Hadoop MapReduce, HDFS, Java, and YARN.
